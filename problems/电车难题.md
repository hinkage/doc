# 2026-02-01
电车难题。

这个问题，我高中毕业后那段时间，在哈佛公开课第一次看到，第一次看到时确实被忽悠过。

现在，这个问题在我看来是最简单的问题。

什么选择是正确的？本质上就是在问，什么选择是正义的，道德的？

也就是说，问题等于，什么是正义和道德。

关于什么是正义，《理想国》一开篇就开始论述。

我自己的观点是：
1. 正义应该被定义为一组规则，当别人也遵守这组规则时，对我自己是有利的。
2. 而且所有人都和我有一样的看法，都认为别人遵守这组规则时对自己有利。

于是这才有了正义，才有了道德，并且这已经内化到人类的DNA中，于是才有了人类群体的秩序，有了城邦，有了政府，然后才有了国家这个概念。

如果没有这个原始正义的规则形成，那么人类就像老虎一样独来独往，不会形成集体，不会出现人类文明。

所以坏人的定义，就是打破规则只图自己利益，出卖其他人利益的人。打破规则的人太多，则个体之间无法互相信任，人类将退化为老虎的独居状态，这种情况下反而打不过老虎，没有进化优势。

```
坏人 = 自私破坏规则的人
正义的个体 = 遵守规则的人
文明 = 规则长期稳定且被大多数个体遵守的结果
退化为老虎状态 = 社会契约失效 → 群体协作消失 → 进化劣势
```

在这个理论下，电车难题中，第一个问题，如果我是电车司机，我可以拐弯吗？
对于只有一个人的那条轨道上的那个人来说，如果我是他，我不会希望自己被主动牺牲。
如果个体可以被主动牺牲，那么所有人都不敢去医院看病了，去了就可能被大卸八块拿去救更多的人。

```
司机不应拐弯。
不是因为冷血，而是因为：
正义不是“最少伤亡”
正义是任何人都愿意生活在其中的规则
能被长期内化、复制、继承
能支撑信任、合作、文明
```

那如果我是司机，而且那 5 个人是孩子，1 个人是罪犯呢？

```
如果孩子不是坏人，而罪犯是坏人，那么牺牲坏人，理应是规则系统的选择，规则应该处罚违规的坏人。
问题是，如果我是司机，我不能代表规则，所以每个人选择不同。
有的人会认为自己操作了，拐弯了，会更因为主动操作导致人死亡而内疚。
有的人会认为牺牲5个孩子，留下坏人，会更内疚。
如果真的是我，那么我会拐弯，如果是别人，他也可以选择不拐弯，这就看个人选择了。
```

所以结论是：不应该拐弯。不应该拉开关。不应该推胖子。不应该拆器官。

但是自然选择给出了其它解法。

有的生物群体，会有个体主动牺牲，换取群体的生存。

人体的免疫系统，会牺牲免疫细胞，换取人体的存在。

要牺牲个体，这种事情在人类社会也是常态，被牺牲掉的人可太多了。

最明显的，自然就是战争中的炮灰，士兵被集体所绑架，只能执行指令去杀人，或者被人杀。

只是，这种对规则的破坏，还没有到把社会秩序整个摧毁掉的程度而已。

所有秩序都会崩溃，所以，人类文明也不是永远都能保持秩序，正义和道德同样可能彻底崩溃，就像人体也会被癌细胞彻底吞噬一样。
